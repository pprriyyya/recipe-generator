# Gradio Recipe Generator 🍳

This project allows you to generate creative recipes based on the ingredients you have.  
It uses **Python** and **Gradio** to provide a colorful and interactive experience.

## 🚀 Features
- Enter your available ingredients
- AI generates random recipes with creative names
- Beautiful Gradio UI with live results
- No downloads needed — everything displayed on the screen

## 📋 Requirements
- Python 3.x
- Gradio
